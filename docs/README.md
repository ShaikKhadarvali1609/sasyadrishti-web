# SasyaDrishti 2.0 — Smart Agriculture Decision Support System

AI Decision Support System for Crop Disease Detection, Agricultural Advisory & Precision Irrigation.

### Features
- **AI Crop Doctor:** Verified plant pathology advisories for all 6 tomato disease classes, complete with CIBRC chemical active ingredients, organic remedies, and bilingual English/Telugu text.
- **Live Meteorological Feed:** Real-time Open-Meteo temperature, relative humidity, precipitation, and FAO-56 reference evapotranspiration ($ET_0$).
- **Precision Irrigation:** FAO-56 Penman-Monteith crop water requirement calculation with 180s pump watchdog auto-shutoff.
- **Research Evaluation:** MobileNetV3-Small neural network evaluation metrics and performance benchmarks.
